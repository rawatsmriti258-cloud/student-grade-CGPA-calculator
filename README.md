# 🎓 Student Grade / CGPA Calculator & Predictor

A modern, responsive web application built with **HTML5**, **CSS3**, and **Vanilla JavaScript** to help students calculate semester SGPAs, track cumulative CGPAs, and predict required academic performance to reach target graduation goals.

---

## ✨ Features

- **📊 Current Academic Stats Dashboard**: Real-time overview of current cumulative CGPA, total completed credits, and active semester SGPA.
- **📝 Semester Course Calculator**: 
  - Dynamically add, edit, or remove subjects with custom credit weights.
  - Choose letter grades mapped to the standard 10-point grading scale (O, A+, A, B+, B, C, P, F).
  - Optional integration with previous academic records (previous CGPA & earned credits) to instantly compute updated cumulative CGPA.
- **🎯 CGPA Target Predictor**: Enter your current CGPA, completed credits, desired target CGPA, and remaining credits to instantly calculate the required GPA needed in upcoming semesters along with feasibility badges (*Achievable*, *Challenging*, *Impossible*).
- **📈 Visual Analytics**: Interactive grade distribution chart powered by **Chart.js** to visualize your semester performance.
- **💾 Local Storage**: Automatically saves your course data and academic progress in your browser so you never lose your work.
- **📋 Built-in Grading Scale Reference**: Quick access to the standard 10-point scale conversion table.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3 (Modern Flexbox/Grid, Custom CSS Variables)
- **Scripting**: Vanilla JavaScript (ES6+)
- **Libraries & Icons**: 
  - [Font Awesome](https://fontawesome.com/) (Icons)
  - [Chart.js](https://www.chartjs.org/) (Data Visualization)
